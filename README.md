# QMS质量管理驾驶舱

面向模块化制造项目的纯前端驾驶舱，用于展示模块箱体生产进度与质量验收态势，无需后端数据库即可运行。本仓库沿用静态前端结构，已同步当前发布版的 RD 工艺路线及交互。

- [在线驾驶舱](https://qms-quality-dashboard.yuanyuxuan2026.chatgpt.site/)
- [RD 工艺路线图](https://qms-quality-dashboard.yuanyuxuan2026.chatgpt.site/dashboard/?project=rd&production=route)

## 主要功能

### 模块箱体生产进度看板

- 箱体制造进度图：展示制造阶段各工序累计完成数量、完成比例和较昨日新增数量。
- 当前箱体分布图：按照“最靠后完成工序 + 下一顺序工序”逻辑展示箱体当前所处节点。
- 工艺路线图：按顶部所选项目展示，已接入 RD-Rockdale；其他项目暂无路线时显示空状态。
- RD 路线支持电脑横排、手机竖排、自适应及手动切换布局；支线默认折叠，支持逐组及全部展开、全部收起，展开时自动延长主线区间。
- 路线卡片同时显示报验箱数、验收通过箱数；抽屉包含总体明细以及新增柱形／累计折线组合图，支持日、周、月、项目全周期。
- 图表以蓝色表示报验、绿色表示验收通过；单一提示框随鼠标移动并自动避让边缘。
- 工序详情抽屉：查看累计完成趋势或当前节点箱体明细。
- 趋势支持日、周、月维度切换。

### 模块箱体质检看板

- 工序质检数据图：展示工序 FPY、资料完成率、验收完成率等指标及亮灯状态。
- 车间质检数据图：按结构车间、装修车间查看质量指标、排名和趋势。
- 班组质检数据图、工人质检数据图：保留功能入口，当前提示“暂未开发”。
- 支持项目、统计范围、工序类型、时间维度和趋势指标切换。

## 本地运行

请在仓库根目录启动静态服务器（路线页通过同源 iframe 与驾驶舱抽屉通信，不建议使用 `file://` 直接打开）：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`，或直接打开 `http://localhost:8080/?project=rd&production=route`。

## 目录说明

- `index.html`：主页面结构。
- `styles*.css`：驾驶舱主题、布局和导航样式。
- `app.js`：页面状态、渲染、抽屉与图表交互。
- `data.js`：基础 Mock 数据与指标定义。
- `p05-*.js`：P05 项目的生产、质量、车间及箱体明细数据。
- `*-integration.js`：看板数据接入和视图整合逻辑。
- `rd-dashboard.js`、`route-integration.js`：RD 项目看板接入与路线抽屉通信。
- `process-demos/`：当前工艺路线视图、拓扑、RD 数量和时间记录、图表及布局逻辑；保留原目录名以兼容已有链接。
- `tests/`：页面结构、数据口径和交互逻辑测试。

## 运行测试

```powershell
Set-Location tests
$failed = 0
Get-ChildItem *.js | ForEach-Object {
  node $_.Name
  if ($LASTEXITCODE -ne 0) { $failed = 1 }
}
exit $failed
```

从仓库根目录验证 RD 数量与趋势统计（Node.js 22 或更高版本）：

```powershell
node --test tests/rockdale-progress.test.mjs tests/route-trend.test.mjs
```

## 数据与接口替换

当前数据直接由 JavaScript 文件提供。接入真实 QMS 后，可保持现有字段结构，将数据加载层替换为 API 请求；页面组件与交互逻辑无需整体重写。

RD 数据来自 `Rockdale学生公寓项目_模块化箱体施工进度_all_精简版_2026-11-02 (2).xlsx` 的 2026-11-02 快照，共 156 个箱体、62 道工序。按箱体编号去重，报验时间有值计入报验；报验和验收通过时间均有值计入通过，`/` 表示未报验或未通过。图表按表内日期统计新增量、累计量；全周期将所有记录汇总为最多六个连续时间区间。数据并非自动实时同步。

对应发布版源码提交：`771ac397d49417ff39d49f9ef4d7160d2748fe1f`。此仓库仅同步其 `public/dashboard/` 静态前端，保留本仓库原有独立文件和测试。
