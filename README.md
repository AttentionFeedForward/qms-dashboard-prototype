# QMS质量管理驾驶舱 Prototype V2

面向模块化制造项目的纯前端交互原型，用于展示模块箱体生产进度与质量验收态势。当前版本内置 P05 货柜模块项目模拟/整理数据，无需连接后端数据库即可运行。

## 主要功能

### 模块箱体生产进度看板

- 箱体制造进度图：展示制造阶段各工序累计完成数量、完成比例和较昨日新增数量。
- 当前箱体分布图：按照“最靠后完成工序 + 下一顺序工序”逻辑展示箱体当前所处节点。
- 工序详情抽屉：查看累计完成趋势或当前节点箱体明细。
- 趋势支持日、周、月维度切换。

### 模块箱体质检看板

- 工序质检数据图：展示工序 FPY、资料完成率、验收完成率等指标及亮灯状态。
- 车间质检数据图：按结构车间、装修车间查看质量指标、排名和趋势。
- 班组质检数据图、工人质检数据图：保留功能入口，当前提示“暂未开发”。
- 支持项目、统计范围、工序类型、时间维度和趋势指标切换。

## 本地运行

可直接打开 `index.html`。为保证浏览器加载和交互行为一致，建议使用静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 目录说明

- `index.html`：主页面结构。
- `styles*.css`：驾驶舱主题、布局和导航样式。
- `app.js`：页面状态、渲染、抽屉与图表交互。
- `data.js`：基础 Mock 数据与指标定义。
- `p05-*.js`：P05 项目的生产、质量、车间及箱体明细数据。
- `*-integration.js`：看板数据接入和视图整合逻辑。
- `tests/`：页面结构、数据口径和交互逻辑测试。

## 运行测试

```powershell
Set-Location tests
$failed = 0
Get-ChildItem *.js | ForEach-Object {
  node $_.Name
  if ($LASTEXITCODE -ne 0) { $failed = 1 }
}
exit $failed
```

## 数据与接口替换

当前数据直接由 JavaScript 文件提供。接入真实 QMS 后，可保持现有字段结构，将数据加载层替换为 API 请求；页面组件与交互逻辑无需整体重写。
